# GAS PDF編集Webアプリ 設計仕様書

## 概要

Google Apps Script（GAS）のWebアプリとして動作するPDF編集ツール。PDF編集はブラウザ側のJavaScriptライブラリ（pdf-lib, PDF.js）が担い、GASはWebアプリの配信とGoogle Drive連携を担当する。

## スコープ

- **Phase 1（基本機能）**: ファイルアップロード、サムネイルプレビュー、メインプレビュー、ページ削除、ダウンロード
- **Phase 2（拡張機能）**: PDF結合、ページ挿入、ドラッグ&ドロップ並べ替え、PDF分割、グリッド表示
- **Phase 3（Drive連携）**: Google Driveからの読み込み・保存（実現可能な範囲で）

## 技術スタック

| 技術 | 用途 |
|------|------|
| Google Apps Script | Webアプリ配信、Drive連携 |
| pdf-lib 1.17.1（CDN） | PDF編集（ページ操作全般） |
| PDF.js 3.11.174（CDN） | PDFのプレビュー表示 |
| clasp | GASプロジェクトのローカル開発・デプロイ |

## ファイル構成

```
project/
├── .clasp.json          … clasp設定
├── appsscript.json      … GASプロジェクト設定
├── Code.gs              … サーバーサイド（doGet, include, Drive操作）
├── Page.html            … メインHTML（レイアウト構造）
├── Styles.html          … CSS（テーマ変数、全スタイル）
├── Scripts.html         … JS（pdf-lib/PDF.js操作、UI制御、タブ管理）
└── recipe.md            … 設計レシピ（開発参考資料、デプロイ対象外）
```

`Code.gs` に `include(filename)` ヘルパーを実装し、`Page.html` 内で `<?!= include('Styles') ?>` / `<?!= include('Scripts') ?>` でインクルードする。

## 機能仕様

### Phase 1: 基本機能

| 機能 | 操作 |
|------|------|
| ファイルを開く | `<input type="file">` でローカルPDFを選択。複数ファイル対応（各タブで開く） |
| サムネイルプレビュー | PDF.jsで各ページをcanvasにレンダリング。サイドバーに縦並び表示 |
| メインプレビュー | サムネイルクリックで右側に拡大表示。ズームイン/アウト対応 |
| ページ削除 | サムネイル選択 → 削除ボタン or Deleteキー。複数選択して一括削除可 |
| ダウンロード | pdf-libで編集後PDFを生成 → ブラウザダウンロード |

### Phase 2: 拡張機能

| 機能 | 操作 |
|------|------|
| PDF結合 | 複数タブを開いた状態で「結合」ボタン → ダイアログでタブの選択と並び順を指定 → 結合結果を新しいタブとして開く。元のタブはそのまま残す |
| ページ挿入 | タブ間でサムネイルをドラッグ&ドロップ。または「挿入」ボタンで別PDFからページ指定 |
| ページ並べ替え | サムネイルをドラッグ&ドロップで移動 |
| PDF分割 | (1) テキスト入力「1-3, 5, 7-10」(2) サムネイル選択 → 「分割」ボタン。分割結果は新しいタブとして開く。元のタブはそのまま残す |
| ページ複製 | 選択ページをその直後に複製して挿入。Undo対応 |
| グリッド表示 | 表示切替ボタンでサイドバー+プレビュー ↔ グリッドを切り替え |

### Phase 3: Drive連携

| 機能 | 操作 |
|------|------|
| Driveから開く | ファイルIDまたはフォルダ内PDF一覧から選択して読み込み |
| Driveに保存 | 編集後PDFをDriveに保存。保存先フォルダ指定可 |
| 大容量対応 | 50MB超はチャンク分割で送受信（詳細はPhase 3実装時に設計） |

## タブ管理

- 複数PDFをタブで同時に開ける
- タブにはファイル名と閉じるボタン（×）を表示
- PDF間でページをドラッグ&ドロップで移動/コピー
- `Alt+←` / `Alt+→` でタブ切り替え（Ctrl+Tabはブラウザ予約済みのため使用不可）
- タブを閉じるにはタブ上の×ボタンを使用

## ページ選択モデル

- **クリック**: そのページのみ選択（他の選択は解除）
- **Ctrl+クリック**: 選択のトグル（追加/解除）
- **Shift+クリック**: 範囲選択（前回クリックしたページから連続選択）
- **選択状態の表示**: 選択中のサムネイルに青い枠線とハイライト背景を表示
- **複数選択時の操作**: 削除、複製、ドラッグ移動はすべて複数選択に対応

## データフロー

```
ローカルPDF選択
  → FileReader で ArrayBuffer 読み込み
  → pdf-lib で PDFDocument.load()（編集用）
  → PDF.js でサムネイル/プレビュー描画
  → 編集操作（ページ削除/挿入/並べ替え等）
  → pdf-lib で pdfDoc.save() → Uint8Array
  → ダウンロード or Drive保存（Base64変換 → google.script.run）
```

## 状態管理

アプリの状態をJSオブジェクトで一元管理:

| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `tabs[]` | Array | 開いているPDFタブ一覧（pdfBytes, ページ情報, ファイル名） |
| `activeTabId` | String | 現在選択中のタブID |
| `selectedPages[]` | Array | 選択中のページインデックス（タブごとに管理） |
| `undoStack[]` | Array | 操作記述子の履歴（最大10段階、タブごと） |
| `redoStack[]` | Array | やり直し用操作記述子 |
| `theme` | String | 現在のテーマ（"light" / "dark"） |
| `viewMode` | String | 表示モード（"sidebar" / "grid"） |

## Undo/Redo方式

メモリ効率のため、操作記述子（operation descriptor）方式を採用する。pdfBytesのスナップショットは保存しない。

| 操作 | 記述子の例 | 逆操作 |
|------|------------|--------|
| ページ削除 | `{type:"delete", pages:[2], data:[copiedPageRef]}` | 削除したページを元の位置に再挿入 |
| ページ挿入 | `{type:"insert", at:3, count:2}` | 該当位置のページを削除 |
| ページ移動 | `{type:"move", from:1, to:4}` | 逆方向に移動 |
| ページ複製 | `{type:"duplicate", source:2, at:3}` | 複製先を削除 |
| ページカット | `{type:"cut", pages:[1,2], data:[copiedPageRef]}` | カットしたページを元の位置に再挿入 |
| ページペースト | `{type:"paste", at:3, count:2}` | ペーストされたページを削除 |

- 各タブが独立した `undoStack` / `redoStack` を持つ
- 最大10段階。超過時は古い履歴を破棄
- 編集操作のたびに `redoStack` をクリア
- 削除操作の場合は、pdf-libの `copyPages` で取得したページ参照を記述子に保持し、Undoで再挿入に使用

## ローディング・進捗表示

| シーン | 表示 |
|--------|------|
| PDF読み込み中 | サムネイル領域にスピナー表示 |
| サムネイル描画 | 可視領域のサムネイルを優先描画（遅延レンダリング） |
| PDF保存/ダウンロード | ツールバーに処理中インジケーター |
| Drive送受信（Phase 3） | プログレスバー（チャンク単位で進捗表示） |

## エラーハンドリング

| ケース | 対応 |
|--------|------|
| PDF以外のファイル選択 | アラートで通知、読み込み中止 |
| パスワード付きPDF | pdf-libエラーをキャッチ → 「暗号化PDFは非対応」と通知 |
| 大きなPDF（50MB超） | チャンク分割でDrive送信 |
| 全ページ削除しようとした | 最低1ページ残す警告 |
| Drive連携エラー | `withFailureHandler` でエラーメッセージ表示 |

## GASの制限事項への対応

| 制限 | 対策 |
|------|------|
| HTMLレスポンスサイズ | JS/CSSはCDNから読み込み |
| `google.script.run` データサイズ（約50MB） | チャンク分割送受信 |
| GAS実行時間（6分） | PDF処理はブラウザ側で完結 |
| iframe制約 | HtmlServiceのiframe内で動作確認が必要 |
