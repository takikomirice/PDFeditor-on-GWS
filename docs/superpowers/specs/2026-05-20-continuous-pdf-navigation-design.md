# Continuous PDF Navigation Design

## Goal

通常表示を縦連続ページ表示に変更し、通常表示では上下キーでスクロール、グリッド表示では上下左右キーでページ選択を移動できるようにする。グリッド表示中に Enter を押した場合は、選択ページの通常表示へ戻る。

## Scope

- 通常表示は単一ページ canvas ではなく、全ページを縦方向に小さな間隔で並べる。
- ズーム操作、画面に合わせる、100% 表示は既存の操作体系を維持する。
- 左右キーは前後ページ選択を維持し、通常表示では選択ページへスクロールする。
- 上下キーは通常表示ではプレビュー領域を縦スクロールし、グリッド表示では現在の列数に基づいて選択ページを上下へ移動する。
- グリッド表示中の Enter は通常表示へ戻し、選択ページを表示位置へスクロールする。

## Architecture

`index.html` の既存構成を維持する。通常表示の DOM は `#preview-container` 内に `.preview-page` を動的生成し、描画済みページは選択変更だけでは再描画しない。再描画の必要性はタブID、PDF更新世代、ページ数、ズーム値から作る render key で判定する。

キー操作は `initKeyboardShortcuts()` に集約したまま、グリッド移動の計算は `computeGridNavigationTarget()` に切り出す。グリッドの列数は実際の DOM または computed style から推定し、レスポンシブな折り返しに追従する。

## Testing

`tests/view-controls.test.mjs` に以下を追加する。

- グリッドの上下左右移動が列数とページ数境界を尊重すること。
- グリッド表示中の Enter が通常表示へ戻ること。
- 通常表示が固定単一 canvas ではなく、動的な連続ページコンテナを使うこと。
- 連続ページ表示用 CSS が縦積みとページ間隔を持つこと。
